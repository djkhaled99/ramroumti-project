# 💗 هدية رمرومتي

مشروع صفحة تفاعلية كاملة، بتاخد رمرومتي برحلة من 16 مرحلة:

🔒 قفل سري ← 🧸 مقدمة ← 🕹️ لعبة القلوب ← 💌 الرسائل السبعة ← 🃏 لعبة الذاكرة ← 🧠 اختبار "قديش بتعرفينا؟" ← 🗓️ قصتنا (خط زمني + **عدّاد أيام حي**) ← 🥺 سؤال المسامحة ← 💗 الرسالة ← 💝 أسباب بحبك ← 🎟️ بطاقات المحكوك ← 📸 **لحظاتنا (معرض الصور)** ← ✉️ رسائل "افتحيها لما..." ← 🎁 الكوبونات والشهادة ← 🎡 عجلة الحظ ← 🌟 سماء نجوم + أمنية + ردّها عليك

✨ **حفظ التقدم**: الصفحة بتتذكر وين وقفت رمرومتي، ولو سكّرتها وفتحتها بيطلعلها زر "كمّلي من وين وقفتي".

💗 **قلوب مع كل كبسة**: بأي مكان بتكبس فيه بالصفحة بتطلع قلوب صغيرة بتطير — إلا إذا الجهاز مفعّل عليه تقليل الحركة.

## 📁 بنية المشروع

```
ramroumti-project/
├── index.html      ← الصفحة كاملة (HTML + CSS + JS بملف واحد)
├── songs/          ← حط أغانيك هون (اختياري)
│   ├── song1.mp3
│   ├── song2.mp3
│   └── song3.mp3
├── photos/         ← حط صوركن هون (اختياري)
│   ├── 1.jpg
│   ├── 2.jpg
│   └── ...
└── README.md
```

## 📸 إضافة صوركن (أهم شي بيخليها شخصية!)

1. اعمل مجلد اسمو `photos/` جنب `index.html`
2. حط صوركن جواه بأسماء **أرقام بالترتيب**: `1.jpg`, `2.jpg`, `3.jpg` ... لحدود 12 صورة
3. الصيغ المدعومة: `jpg` · `jpeg` · `png` · `webp`

الصفحة بتلاقي الصور لحالها وبتعرضهن متل صور البولارويد، وبتكبر لما تكبس عليها.

**التعليقات**: كل صورة إلها تعليق تحتها. عدّلهن من قائمة `photoCaps` بأول الـ `<script>`:

```js
const photoCaps=[
 'أول صورة إلنا 🥹','ضحكتك يلي بتجنن 😍', ...
];
```

> إذا ما في مجلد صور، القسم **بينخبى لحالو** وبتكمل الرحلة عادي بدون أي فراغ أو خطأ.

## ⏱️ عدّاد الأيام

بقسم "قصتنا" في عدّاد حي بيعدّ الأيام والساعات والدقايق والثواني من أول "بحبك". عدّل التاريخ من هون:

```js
const LOVE_DATE=new Date(2024,11,31,23,59);   // (سنة, شهر-1, يوم, ساعة, دقيقة)
```

⚠️ انتبه: **الشهر بيبلش من صفر** — يعني `11` = كانون الأول (ديسمبر)، و`0` = كانون الثاني (يناير).

## 🎵 إضافة الأغاني

1. حط ملفات mp3 داخل مجلد `songs/` بأسماء: `song1.mp3`, `song2.mp3`, `song3.mp3`
2. إذا بدك أسماء أو عدد مختلف، افتح `index.html` ودوّر على قائمة `SONGS` بأول الـ `<script>` وعدّلها:

```js
const SONGS=[
  {src:'songs/song1.mp3', name:'أغنية 1'},
  {src:'songs/song2.mp3', name:'أغنية 2'},
  {src:'songs/song3.mp3', name:'أغنية 3'},
];
```

- الأغاني بتشتغل تلقائياً بعد ما تفتح القفل، وبتنتقل لحالها من وحدة للتانية.
- زر ⏭️ فوق بينقل الأغنية.
- إذا الملفات مو موجودة → بيشتغل اللحن المبرمج (fallback) بدون أي خطأ.

## 🧪 التجربة محلياً

الأسهل تشغّل سيرفر محلي بسيط من داخل المجلد:

```bash
# Python
python -m http.server 8080

# أو Node
npx serve .
```

بعدين افتح: `http://localhost:8080`

(فتح الملف مباشرة بـ file:// بيشتغل غالباً، بس السيرفر المحلي أضمن للصوت.)

## 🔐 كلمة السر

الجواب بشاشة القفل: أي كلمة فيها "رمروم" (رمرومتي، رمرومة...).
تقدر تعدّل الأجوبة من متغير `answers` بالـ script.

## ✏️ تعديل المحتوى

كل النصوص بمكان واحد بأول الـ script:

- `memories` → الأظرف السبعة (أيقونة، عنوان، نص)
- `couponData` → الكوبونات الستة
- `story` → محطات الخط الزمني "قصتنا" (سنة، أيقونة، عنوان، نص)
- `quizQs` → أسئلة الاختبار (سؤال، خيارات، رقم الجواب الصح `c`، رد للصح والغلط)
- `scratchSecrets` → أسرار بطاقات المحكوك
- `wheelPrizes` → جوائز عجلة الحظ
- `loveReasons` → أسباب "بحبك" (بتطلع عشوائياً وحدة وحدة)
- `openWhen` → رسائل "افتحيها لما..." (أيقونة، شرط، رسالة)
- `photoCaps` → تعليقات الصور بالترتيب
- `LOVE_DATE` → تاريخ أول "بحبك" (عدّاد الأيام)
- رسالة الاعتذار النهائية → داخل `<section id="finale">` بالـ HTML

## 💌 وين يوصل ردّها

بآخر الصفحة (قسم النجوم) في مكان تكتبلك فيه رمرومتي ردها. لتحدد لوين يوصل، عدّل هالسطر بأول الـ script:

```js
const REPLY={whatsapp:'', email:'prencemero@gmail.com'};
```

- **واتساب** (مفضّل): حط رقمك بصيغة دولية بدون + ولا أصفار، مثال `963991234567` بخانة `whatsapp`. بيفتح واتساب مباشرة برسالتها جاهزة.
- **إيميل**: إذا خليت `whatsapp` فاضي، بيفتح تطبيق الإيميل ويبعتلك عالعنوان بخانة `email`.
- إذا الاتنين فاضيين، بينسخ ردها عالكليبورد.
